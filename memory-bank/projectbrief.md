# Project Brief — Grimórios de Arcana

## Identidade

- **Nome:** Grimórios de Arcana
- **Categoria:** sistema TTRPG virtual
- **Plataforma inicial:** aplicação web
- **Stack desejada:** Angular
- **Publicação desejada:** GitHub Pages usando Angular gh pages
- **Idioma inicial:** português do Brasil, salvo decisão posterior

## Visão

Criar uma experiência digital para jogar Grimórios de Arcana, transformando os elementos do sistema TTRPG em uma interface virtual clara, imersiva e útil durante a sessão.

## Objetivo da primeira versão

Entregar um MVP navegável que valide a experiência central do sistema antes de ampliar escopo. A primeira versão deve priorizar:

- apresentação clara do universo e da proposta do sistema;
- criação ou montagem de personagem;
- consulta de regras, atributos e recursos relevantes;
- suporte mínimo à condução de uma sessão virtual;
- experiência responsiva para desktop e telas menores;
- implantação pública e repetível no GitHub Pages.

## Fora do escopo inicial, salvo validação

- backend com autenticação e persistência multiusuário;
- matchmaking ou comunidade pública;
- aplicativo mobile nativo;
- marketplace de conteúdo;
- automação completa de mestre, combate ou narrativa por IA.

## Critério de sucesso do MVP

Uma pessoa nova consegue entender o que é Grimórios de Arcana, iniciar a preparação de um personagem e encontrar os recursos básicos necessários para uma sessão sem depender de documentação externa.

## Premissas a validar

- O público inicial conhece TTRPG, mas pode não conhecer Grimórios de Arcana.
- O primeiro release pode funcionar com dados locais/mockados, sem backend.
- A prioridade é provar a experiência do produto, não cobrir todo o sistema de regras.
