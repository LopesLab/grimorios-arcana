# Memory Bank — Grimórios de Arcana

Este diretório concentra o contexto durável do produto, as decisões de negócio e a evolução do projeto.

## Como usar

Antes de iniciar uma nova etapa, consulte principalmente `activeContext.md`, `projectbrief.md` e `progress.md`.
Depois de uma decisão relevante, atualize o documento correspondente e registre a mudança em `progress.md`.

## Ordem de leitura recomendada

1. `projectbrief.md` — visão e escopo do produto.
2. `productContext.md` — problema, público e proposta de valor.
3. `activeContext.md` — foco atual e decisões pendentes.
4. `systemPatterns.md` — princípios de arquitetura e produto.
5. `techContext.md` — stack, ambiente e publicação.
6. `progress.md` — histórico e próximos marcos.

## Status desta base

Esta é a versão inicial, criada antes da implementação do Angular. Itens marcados como hipótese devem ser validados com o responsável pelo produto.
